> Inspired by the excellent [vscode-pokemon](https://github.com/jakobhoeg/vscode-pokemon) extension by Jakob Hoeg, but built specifically for Microsoft Visual Studio.

## Features

- 🎮 Animated Pokémon companion inside Visual Studio
- ✨ Smooth animated GIF sprites
- 📏 Multiple Pokémon sizes
- 🔄 Easily switch between Pokémon species
- 💾 Remembers your spawned Pokémon between Visual Studio sessions
- 🎨 Automatically adapts to your Visual Studio theme (light/dark)
- ⚡ Lightweight and designed specifically for Visual Studio

## Usage

After installing the extension:

1. Open Visual Studio.
2. Open the **View** menu.
3. Select **Pokémon**.
4. Choose your favorite Pokémon, give it a nickname, and spawn it.
5. Enjoy coding with your new companion!

Your spawned Pokémon will automatically be restored the next time Visual Studio starts.

## Building

Clone the repository:

```bash
git clone https://github.com/FabioMusi04/VS2026-Pokemon.git
```

Open the solution in Visual Studio and build the project.

To test the extension:

- Press **F5**
- An Experimental Visual Studio instance will launch with the extension installed.
